# 常见问题

## 模型和价格在哪里看

返回你使用的 Yuai 站点，打开「模型广场」。账户分组和密钥模型限制会影响实际可用范围，模型 ID 要完整复制，不能只填显示名称或自行猜测别名。

## Base URL 为什么不一样

Claude Code 使用网关根地址。Codex、OpenAI SDK 和大多数 OpenAI 兼容客户端使用根地址加 `/v1`。HTTP 示例还要追加具体接口路径。文档站的网址不提供模型 API。

出现 404、HTML 页面或 `/v1/v1` 时，先检查路径，再检查模型协议。详见 [快速开始](/guide/quickstart)。

## 常见错误

| 现象               | 优先检查                                  | 下一步                                |
| ------------------ | ----------------------------------------- | ------------------------------------- |
| 400 / 422          | 请求 JSON、参数、模型与协议是否匹配       | 精简为最小请求，查看具体字段错误      |
| 401                | 密钥是否完整、有效，鉴权头是否正确        | 更新密钥，确认程序读取了新环境变量    |
| 403                | 模型、分组、IP 或账户权限                 | 核对控制台权限与服务端提示            |
| 402 / 额度不足提示 | 账户资金来源、订阅与密钥额度              | 检查钱包和密钥；以响应内容为准        |
| 404                | API 根地址、重复 `/v1`、接口路径、模型 ID | 按该客户端教程重新核对                |
| 429                | 限流、并发过高或临时繁忙                  | 降低并发，遵循 Retry-After 或指数退避 |
| 5xx                | 网关或上游服务临时异常                    | 保存请求 ID，稍后有限重试             |

不同协议和上游的状态码可能不同，先读响应里的 `error` 内容。鉴权、权限、额度错误不应盲目重试；对已经开始输出或产生副作用的 Agent 任务，先确认完成状态。

## 命令行能用，桌面端不能用

桌面程序通常不会继承你在另一个终端临时设置的变量。设置用户级环境变量后完全退出并重开应用，或从已经设置变量的终端启动。远程主机、WSL 和容器也有各自独立的环境。

## 如何选择协议

Codex 使用 Responses。Claude Code 使用 Anthropic Messages。其他工具按模型支持的接口选择 Chat Completions 或 Responses。不要通过修改模型名称来假装协议兼容。

## 如何联系支持

使用 Yuai 首页、控制台公告或运营方提供的联系入口。反馈时附上发生时间、客户端及版本、模型 ID、请求 ID、状态码与脱敏错误内容。不要发送 API 密钥、登录 Cookie 或含敏感代码的完整请求。

## 密钥泄露怎么办

立即停用或删除旧密钥，创建新密钥并更新工具，再检查异常使用记录。详见 [密钥轮换](/guide/api-keys#密钥泄露或轮换)。

## 服务协议与退款规则

以你使用的 Yuai 站点公布的用户协议、隐私政策、购买说明及运营方答复为准。文档中的接入说明不替代这些条款。
