# 用量与计费

在「模型广场」查看当前价格，在「钱包」查看账户可用余额与订阅，在「使用日志」核对实际调用。购买前以当前页面展示的币种、单位、价格、额度和有效期为准。

## 模型价格怎么看

不同模型可能按 token、请求次数或其他计费方式结算。按 token 计费时，输入、输出及缓存命中可能使用不同价格；分组也可能影响最终计价。先确认单位是每百万 token、每次还是其他单位，再比较成本。

`/v1/models` 提供模型标识，并不是完整的价格接口。客户端自己显示的估算金额也不替代 Yuai 的实际使用记录。

## 钱包与订阅

余额与订阅分开管理。钱包页面可能提供订阅优先、钱包优先、仅订阅或仅钱包等偏好；实际可选项以账户界面为准。请检查当前选择与有效订阅，再判断一次调用会使用哪种资金来源。

充值到账、兑换比例、套餐额度、重置周期和退款条件均以站点当时展示的购买说明为准。不要把其他服务商的套餐规则套用到 Yuai。

## 查看一次请求的用量

进入 **控制台 → 使用日志**，根据时间、密钥或模型定位调用。重点检查模型、输入/输出 token、缓存用量、计费信息和请求状态。

流式响应需要完整读取。HTTP 连接成功只表示开始响应；后续仍可能出现模型或网关错误。若发生中断，请结合日志判断，避免重复提交较大的任务。

## 调价与预算

开始长任务前检查当前模型价格与分组。使用独立密钥并设置额度、有效期和模型限制，减少失控任务的影响范围。价格变动及具体结算规则以站点公告和实际配置为准。

操作方法见 [API 密钥与成本控制](/guide/api-keys)。发现扣费疑问时提供请求时间、模型、请求 ID 和脱敏日志，不要提供完整密钥。
