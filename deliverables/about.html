Coding Agent 的模型网关

为 Claude Code、Codex 和你的应用提供统一的模型入口。使用熟悉的工具，通过兼容接口连接可用模型，在控制台管理密钥与用量。

开始接入 ↗ 查看模型

从这里开始

  1. 登录账户，在 API 密钥 中创建专用密钥。
  2. 从首页复制 API 地址，按 接入文档 配置工具。
  3. 选择可用模型，完成一次短请求，再到 使用日志 核对调用。

支持的工具

Claude Code、Codex CLI 与桌面端、OpenCode、Qwen Code、pi、Cline、Aider，以及使用 OpenAI 或 Anthropic 兼容 SDK 的应用。

模型支持的接口、工具调用和多模态能力各不相同，以模型广场和当前账户权限为准。

地址与协议

Claude Code 使用首页 API 根地址；Codex 和 OpenAI 兼容客户端通常使用根地址加 /v1。直接发送 HTTP 请求时还需要具体接口路径。

文档站仅提供说明。不要将文档网址填写为 API 地址，也不要重复添加 /v1。

管理用量与成本

按项目分配密钥，设置额度、有效期和模型限制。长任务开始前检查价格与账户可用额度，运行后查看使用日志。

价格、套餐、充值和订阅规则以模型广场、钱包及站点公告为准。详细操作见 用量与计费。

使用帮助

遇到问题可先查看 常见问题。需要反馈时，通过站点公告中的联系渠道提供客户端版本、模型、时间、请求 ID 和脱敏错误信息。

请妥善保管密钥；不要在反馈、截图或公开代码中发送完整密钥。发现泄露后立即停用并更换。

Yuai 基于 New API · QuantumNous，源自 One API · JustSong。New API 遵循 AGPL v3.0。
