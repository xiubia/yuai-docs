# Yuai 服务条款准备稿（未发布）

这份文件供运营方整理事实并交由适当人员审阅，不随文档站构建，不构成当前用户协议。

## 上线前需要明确的信息

- 运营主体、适用地区和有效联系方式。
- 提供的服务范围、账户资格、允许用途和禁止行为。
- 各模型与上游服务适用的使用要求。
- 计费单位、充值与订阅规则、变价通知、争议处理和退款条件。
- 收集的数据类别、用途、存储位置与期限、访问权限、删除申请及安全事件处理。
- 服务中断、账户限制、终止、责任范围和争议解决方式。

## 可作为说明部分的文字

Yuai 提供兼容接口，帮助用户将支持的开发工具和应用连接到可用模型。用户应妥善保管账户与 API 密钥，并在调用前确认模型、权限、价格和额度。可用模型与服务能力以站点当时的配置为准。

涉及个人信息、商业秘密或受限制数据时，用户应先确认自身权限及相关数据处理要求，再决定是否提交。运营方需要如实披露实际日志、上游数据处理及保留安排，不能用未经核实的“不记录”或“不训练”承诺替代说明。
